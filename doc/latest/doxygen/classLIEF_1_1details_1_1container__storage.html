Detailed Description

template<class T, bool = std::is_reference_v<T>>
class LIEF::details::container_storage< T, bool >

Storage of the container iterated by a ref_iterator or a filter_iterator.

If the iterator is instantiated with a reference (e.g. std::vector<Section*>&), the container is borrowed the iterator and the storage is a pointer on it. Otherwise, the storage holds the container itself and copying the iterator copies the container.
